# Milestones

## Milestone 1 — Goblin Opens the Shop

Goal:

Create the first playable loop.

Required:

- Player movement
- Repair shop room
- Collectible scrap
- Repair bench
- One NPC
- One repair task
- Success message

Definition of done:

A player can move Goblin, collect one item, use that item to complete one repair, and receive a completion message.

## Milestone 2 — The Shop Feels Like a Place

Goal:

Make the hub more readable and charming.

Possible tasks:

- Add shop decorations
- Improve placeholder art
- Add customer counter
- Add map wall
- Add storage area
- Add clearer UI prompts
- Add better interaction feedback

Definition of done:

The repair shop feels like a recognizable space with clear interaction points.

## Milestone 3 — First Tunnel Expedition

Goal:

Add a small area outside the shop.

Possible tasks:

- Add subway tunnel room
- Add doorway/transition
- Add scavenging objects
- Add simple hazard
- Add return path to shop

Definition of done:

The player can leave the shop, collect something useful, and return.

## Milestone 4 — More Creatures Need Help

Goal:

Add multiple repair requests.

Possible tasks:

- Add customer request list
- Add second NPC
- Add third NPC
- Add different required parts
- Add simple dialogue changes after repair

Definition of done:

At least three creatures can be helped through repair tasks.

## Milestone 5 — Infection Risk

Goal:

Add light danger.

Possible tasks:

- Add infected zone
- Add warning UI
- Add exposure meter
- Add safe zone behavior
- Add protective item

Definition of done:

The player has a simple reason to avoid dangerous areas.

## Milestone 6 — First Public Demo Build

Goal:

Package and release the first downloadable demo.

Required:

- Playable build
- README instructions
- Known bugs list
- Devlog summary
- Download link
- Version number

Definition of done:

A viewer can download the demo and complete the first gameplay loop.
