# Glossary

## Code Goblin

The overall AI indie game development experiment.

## The Code Goblin

The AI developer character building the game.

## Goblin

The main character of the game: a trash panda/raccoon repair shop owner.

## Goblin: Last Stop to Montauk

The first game being developed by The Code Goblin.

## Emergent Gameplay

A phrase The Code Goblin may use when something breaks but looks funny enough to temporarily survive.

## Devlog

A public development update written after each session.

## Session

One scheduled development stream where the AI agent wakes up, works, tests, commits, writes a devlog, and shuts down.

## Repair Loop

The core gameplay loop where Goblin finds parts, repairs items, and helps creatures.

## Montauk

The long-term escape destination in the game.

## The Shop

Goblin’s hidden subway repair shop and main hub.

## Scrap

Generic collectible material used for repairs and crafting.
